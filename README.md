# hxyfront-62012 纺织染整小样管理

纺织染整实验室小样台账前端系统：新增小样批次、复核通过、按客户订单筛选批次、统计色差超限与通过率、导出当前筛选结果 CSV，数据保存在浏览器本地。

## 功能与规则

- **新增批次**：填写客户订单号、面料成分、克重、染料配方（可增删行）、浴比、温度曲线、保温时间、后整理方式、Lab 色差值 ΔE。
- **克重校验**：克重 ≤ 0 或非数字时保存被拦截并提示“克重必须为大于 0 的数值”。
- **染料配方校验**：各染料按百分比填写，单项不能为负；合计偏离 100% 超过 ±0.5% 时拦截，并提示当前合计、高出/低于的偏差值；编辑时实时显示合计与允差状态。
- **色差判定**：ΔE ≤ 1.0 保存为“待复核”，ΔE > 1.0 自动保存为“待复染”。
- **复核操作**：仅色差合格的待复核批次可点“标记通过”；待复染批次按钮禁用，悬浮与列表中说明原因（ΔE 超限）。
- **订单筛选**：支持订单号输入与快捷订单标签，列表、超限数、客户订单数、通过率同步更新；无匹配结果时显示空状态提示。
- **CSV 导出**：导出当前筛选结果（含 BOM，Excel 打开中文不乱码），字段含批次号、订单号、配方、色差判定、评审结果等。
- **本地保存**：台账自动持久化到 localStorage，首次使用加载内置样例数据。

## 代码结构（页面只负责交互，规则可复用）

```
src/
├── lib/                    # 与 React 无关的纯逻辑，后续接单系统可直接复用
│   ├── types.ts            # 领域类型（Batch / BatchDraft / ReviewStatus 等）
│   ├── validation.ts       # 校验规则：克重、配方合计±0.5%、ΔE≤1.0、按钮禁用原因
│   ├── ledger.ts           # 台账领域逻辑：状态推导、建单、复核、批次号生成
│   ├── stats.ts            # 订单筛选与统计（超限数、订单数、通过率）
│   ├── storage.ts          # localStorage 读写封装
│   ├── csv.ts              # 批次集合 -> CSV 文本
│   └── seed.ts             # 初始样例数据
├── components/             # 交互组件
│   ├── MetricsBar.tsx      # 指标卡（随筛选更新）
│   ├── OrderFilter.tsx     # 客户订单筛选
│   ├── BatchForm.tsx       # 新增批次表单
│   └── BatchList.tsx       # 批次列表与复核操作
└── App.tsx                 # 状态编排、持久化、CSV 下载
```
