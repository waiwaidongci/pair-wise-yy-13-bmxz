# hxyfront-62012 纺织染整小样管理

纺织染整实验室小样台账：新增小样批次、染料配方校验、Lab 色差复核、按客户订单筛选与 CSV 导出。数据保存在浏览器 localStorage。

## 业务规则

- **新增校验**：订单号、面料成分必填；克重必须为大于 0 的数字。
- **染料配方**：按百分比录入多行染料，可增删行；每行染料名称必填、百分比为非负数字；合计须在 **100% ± 0.5** 以内，超出时提示合计偏高/偏低及具体百分点，明细有误会定位到具体行。
- **色差复核**：ΔE ≤ 1.0 的批次保存为「待复核」，可点击「复核通过」；ΔE > 1.0 保存为「待复染」，通过按钮禁用并悬停说明原因。
- **订单筛选**：订单号搜索/快捷选择同步更新批次列表、指标（批次总数、色差超限、订单数、通过率）；无结果显示空态提示。
- **导出**：CSV（带 UTF-8 BOM，Excel 可直接打开）只包含当前筛选结果。

## 代码结构

```
src/
├─ lab/                 # 与框架无关的可复用逻辑（后续接单系统直接引用）
│  ├─ types.ts          # 领域类型、状态枚举、限值常量
│  ├─ validation.ts     # 字段校验、配方合计校验、色差评定（纯函数）
│  ├─ stats.ts          # 统计指标、订单筛选、订单列表、批次号生成（纯函数）
│  ├─ storage.ts        # 序列化纯函数 + 可替换的 localStorage 存储适配器
│  ├─ csv.ts            # CSV 转义/转换纯函数 + 浏览器下载
│  ├─ seed.ts           # 首次打开的种子台账
│  └─ index.ts          # 统一出口
├─ components/          # 页面交互组件
│  ├─ SampleForm.tsx    # 新增表单与实时校验反馈
│  ├─ OrderFilter.tsx   # 客户订单筛选
│  ├─ BatchList.tsx     # 批次卡片、状态徽标、复核按钮
│  └─ StatsBar.tsx      # 指标条
└─ App.tsx              # 仅负责状态编排，不包含校验/统计规则
```

`src/lab` 不 import React / 组件，校验与统计均为纯函数；存储后端实现了 `BatchStore` 接口，接单系统接入时可替换为接口实现而不动页面逻辑。
